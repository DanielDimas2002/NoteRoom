# 📚 Sistema de Gestão de Turmas

Bem-vindo ao **Sistema de Gestão de Turmas**, uma aplicação web que facilita a criação e gerenciamento de turmas para cursos. 🌐💻

## 🎥 Demonstração

Veja o vídeo demonstrativo da aplicação:  
[Assistir ao vídeo](https://youtu.be/BzbbesLuR2g?si=rlqUGlcl6f9WtkGc) 🎬

---

## 🚀 Funcionalidades

- **Criação de Turmas**: Crie turmas de maneira simples, com informações como disciplina, turno, e datas. 📝
- **Edição de Turmas**: Edite os dados das turmas já cadastradas de forma rápida. ✏️
- **Visualização de Turmas**: Visualize todas as turmas criadas em um painel dinâmico. 👀
- **Formulários de fácil uso**: Preencha rapidamente o formulário para adicionar ou editar turmas. 📅

---

## 📌 Como Usar

1. **Abrir o Pop-up de Criação de Turma**  
   Clique no botão **"Criar Turma"** para abrir o formulário de criação de turmas. 🏫

2. **Preencher o Formulário**  
   Complete os campos: disciplina, turma, turno, data inicial e data final. 📝

3. **Submeter o Formulário**  
   Clique em "Criar Turma" para salvar os dados. Sua turma aparecerá no painel de controle. 💾

4. **Editar ou Excluir Turmas**  
   Para editar ou excluir uma turma, clique no cartão da turma e faça as alterações necessárias. ✨

## ⚙️ Tecnologias Usadas

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Node.js (Express)
- **Banco de Dados**: JSON (para persistência local)
